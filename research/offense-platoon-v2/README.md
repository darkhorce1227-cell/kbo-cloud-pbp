# 공격 생산성 → 승률 개선판 v2: 구현 및 검증

**2026-11-06: 구현 완료. 예측력 개선은 입증되지 않아 공식 적용을 보류한다.**

기존 실패를 이유로 분석을 끝내지 않고 실제 투수 손, 타자/투수 좌우 스플릿,
평소 라인업 대비 변화를 구현했다. 변수를 구현하는 것과 새로운 경기
예측력을 확보하는 것은 별개의 문제다.

## 변경 사항

1. **실제 투수 손:** KBO 공식 프로필의 선수 ID와 투타 표기로 투수 460명을
   모두 확인했다. 언더핸드 ‘우언’도 우투로 처리한다. PBP의 stand나 릴리스
   좌표로 추정하지 않는다. URL·수집 시각·HTML SHA256을
   pitcher_hands_20261106.json에 보존했다.
2. **라인업 변화:** 현재 타순의 출루/총루타/삼진 비율을 직전 10경기
   라인업과 비교한다. 양쪽 라인업의 선수 능력은 모두 목표일 전날까지의
   동일한 정보로 평가한다. 원시 생산성을 팀 공격력에 다시 더하지 않는다.
3. **실제 좌우 상성:** 타자의 vs LHP/RHP와 상대 선발의 vs LHB/RHB 기록을
   사용한다. 전체 성적은 120 PA, split은 200 PA의 사전표본으로 축소한다.
   투수 전문 상성은 리그 공통 좌우 효과를 뺀 잔차만 사용해 타자 쪽
   공통 상성의 중복 반영을 줄였다.
4. **득점부터 학습:** 30일 리그 득점 환경을 offset으로 두고 학습 기간의
   Poisson 회귀로 계수를 추정한다. F5와 6회 이후 득점을 각각 양수로
   학습해 합친다. Full PMF는 두 비음수 득점 증분의 합성곱이다.
   기술통계 차이에서 승률 %p를 수동으로 정하는 단계는 없다.

선발 노출은 과거 등판의 예상 이닝을 이용한 단순 근사다. 불펜 좌우 구성은
이전 30일 등판 비중의 근사이며 당일 확정 로스터/감독 운용을 완전히
복원한 것이 아니다. 타순 가중치는 고정 연구 가중치로, 검증된 개인별
예상 타석수 모델이라고 부르지 않는다.

## 같은 경기에서 비교한 시간순 검증

- context: 리그 환경, 팀 공격/상대 실점, 선발·불펜 전체 능력, 홈/파크 근사.
- lineup_delta: 위 모델 + 평소 라인업 대비 변화.
- lineup_platoon: 위 모델 + 타자/선발의 실제 좌우 상성.

아래는 최종 lineup_platoon과 context의 비교다. Log loss는 낮을수록 좋다.
차이는 개선판−기준이며 양수는 악화다.

득점 분포 NLL도 두 기간의 F5/Full에서 최종 개선판 점추정치가 모두
나빠졌다. 라인업 변화만 추가한 중간 모델도 안정적인 이득이 없었다.
모든 비교와 구간은 run-20261106/results.json에 있다.
구간은 탐색적·비보정 비교다. 다중 검정과 날짜 간 시계열 의존성을
모두 해결하는 신뢰구간으로 해석하지 않는다.

**판단:** “좌타자가 많다” 또는 “투수가 좌타자에게 약했다”는 사실만으로
공식 승률을 얼마나 움직일지 아직 정당화할 수 없다. 이번 구현을
새 보정 계수로 채택하지 않는다. 좌우 상성이 야구에서 무의미하다는
결론도 내리지 않는다.

## 검증 범위와 한계

- 원본 2024/2025 PBP 각 736경기에서 9월 말까지를 사용하고, 2026은
  10월 12일까지 정규시즌 720경기를 사용했다. 전체 2,152경기 중
  20250419NCHH02025는 5회 완료를 확증할 수 없어 제외했다.
  입력 피치 stable key 중복은 0이다.
- 원본 SHA256은 study_plan.json, 실제 데이터/코드 해시는
  run-20261106/audit.json에 기록했다.
- 통계 갱신은 해당 날짜의 전체 예측이 끝난 뒤에 수행했다.
  더블헤더 같은 날짜 경기도 서로의 결과를 사용하지 않는다.
- 과거 라인업/선발은 PBP 첫 9명/첫 투수에서 복원한 **사후 proxy**다.
  대타나 선발 변경의 경기 전 발표 시각을 독립적으로 증명하지 못한다.
- 현재 공식 프로필은 **고정 속성인 투구 손** 확인에만 썼다.
  과거 특정일의 엔트리, 부상, 구종, 로스터 활성 상태를 뜻하지 않는다.
- 2025/2026은 이전 연구에서 이미 관찰한 시즌이다. 이번 계획과
  하이퍼파라미터는 결과 확인 전에 고정했지만, 프로젝트 관점의
  새로운 독립 holdout이나 prospective CLEAN PRE라고 부르지 않는다.
- Full W/D/L은 득점 PMF의 **진단**이다. 연장전/말 공격 생략/끝내기
  규칙을 구현한 공식 최종 승률 엔진이 아니다. 2026 개선판은 무승부를
  9.47% 예측했지만 관측치는 2.57%였다. 이를 정식 Full 배당/EV에 쓰지 않는다.
- 원래 Operational Champion의 매칭된 재현 가능 예측이 없어,
  그 Champion보다 좋아졌거나 나빠졌다고 주장하지 않는다.

## 적용 결정

공식 Champion, 기존 v1.3 spec, v0.9 prospective gate, PRE/LOCK,
Practical/Raw/Max/Actual은 변경하지 않았다. 새 모듈은 연구 전용이다.

승격 검토에는 동결된 버전과 독립적으로 시각이 기록된 라인업/선발을
쓰는 새로운 미래 표본이 필요하다. 기존 검증 기간에 계수를 맞춰
고치지 않는다. 개인별 예상 타석/대타, 끝내기·연장전 경로는 남은
별도 연구 과제다.
